# Design Direction

VideoFuse should feel like a focused utility, not a full editor.

## MVP Screens

- Home
- Extract Frame
- Stitch Videos
- Processing Progress
- Export Result

## UX Principles

- Open app, select utility, choose files, export.
- No login in MVP.
- No onboarding gate in MVP.
- Keep controls minimal and task-specific.
- Use clear status states: selecting, ready, processing, success, failed, cancelled.
- Explain failures in plain language.
- Make the selected frame obvious in both the timeline grid and detailed strip.
- Keep multi-video ordering visible before merging begins.

## Visual Direction

- Modern, quiet, and compact.
- Prioritize clarity over decoration.
- Use accessible tap targets.
- Avoid complex timeline UI.
- Avoid social-feed or template-marketplace patterns.
