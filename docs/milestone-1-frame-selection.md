# Milestone 1 — Frame Selection

## Status

Completed and verified on a physical Android device.

## Delivered

- Single-video selection for frame extraction.
- First-frame and last-frame previews.
- Custom frame picker with a cached timeline grid.
- Thumbnail timestamps based on the source video's detected frame rate.
- Detailed surrounding-frame strip with selected-frame highlighting and centering.
- Direct time entry and slider/grid navigation.
- Frame saving through an Android Downloads chooser flow.
- Large-file safeguards and background thumbnail processing.
- Media3/native decoding path with cache reuse and loading states.

## Acceptance outcome

The user can choose a video, locate a frame using the cached timeline or exact time
controls, preview nearby frames, and save the selected frame without modifying the
source video.

## Next

The next milestone focuses on merging multiple videos into one reliable MP4 export.
